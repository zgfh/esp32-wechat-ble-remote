# 遥控器控制器外壳（尺寸待确认草稿）

适用方案：ESP32-S3、PC817 焊接板、保留原电池的遥控器并排放置。源文件为 `case.scad`，独立于固件，不涉及 Wokwi 部署。

**此版本不能直接视为实物适配完成。** N8R2 仅说明存储配置，不能确定开发板的长宽、USB 位置或安装孔。以下尺寸是设计占位值，不是厂家数据。

| 模块 | 假设安装包络：长×宽×高（mm） |
|---|---|
| ESP32，含排针及底部焊点 | 65×30×18 |
| 光耦洞洞板 | 40×30×15 |
| 遥控器，保留原外壳及电池 | 65×38×20 |

按这些参数，盒体约 87.8×136.8×33.8 mm，安装耳使总长约 111.8 mm。`include_remote=false` 可移除遥控器舱。为便于修改采用并排布局，实测后可缩小。

## 结构与装配

- 底盒＋平面上盖，四角 M2.5 自攻螺丝。上盖孔 2.6 mm、底盒盲孔 2.0 mm；建议试配 M2.5×10，勿强行拧入。四根螺柱连到底板。
- 每模块有两根 4 mm 高支撑条；底部穿扎带孔，把模块绑在支撑条上。裸板需按实物焊点位置调整支撑条，并加绝缘垫；不能让支撑顶住元件、短接焊点或压住遥控器按键。
- 两侧安装耳开 4.5 mm 通孔，便于用 M4 螺钉安装；装配前先固定底盒，再装电子模块。
- 侧面顶部留 18×10 mm 线缆缺口，适合将 USB 延长线引出，**并非按实测位置设计的 USB 插座孔**。线缆在盒内另加扎带固定，避免拉扯接口。
- 遥控器维持自己的电池与绝缘；支撑条和扎带不得压天线。天线附近尽量不放螺丝、导线束或金属支架。
- 该版本有底部绑带孔和开放线缆口，无防水等级；安装环境确认后再决定密封、排水和固定形式。

## 定稿前测量

1. ESP32 板长宽、总高（含排针和焊点）、USB 插头插入后的空间、天线方向。
2. 光耦最终用洞洞板还是模块，其长宽高；不要按临时面包板估算成品。
3. 遥控器外壳长宽高、按键及电池盖的位置；是否整个装入本盒。
4. 安装空间和固定面孔距，以及是否有雨水、日晒、车辆振动。

## 打印与导出

底盒底面朝下，上盖平面朝下，各自独立打印；建议初始层高 0.2 mm、至少 3 圈外壁。材料按实际环境选择，先打印安装孔及支撑局部试配，再打印整盒。

当前环境未发现 OpenSCAD，尚未生成 STL 或完成渲染/网格验证。模型仅依赖 OpenSCAD 核心功能，无 BOSL2。macOS 安装命令供参考（未执行）：`brew install --cask openscad`。

安装后在本目录执行：

```sh
openscad -D 'part="bottom"' -o case-bottom.stl case.scad
openscad -D 'part="lid"' -o case-lid.stl case.scad
openscad -D 'part="assembly"' --viewall --autocenter --imgsize=1200,900 -o preview.png case.scad
```

导出后需检查所有警告、预览中的孔位和支撑条，再做实物试装。
