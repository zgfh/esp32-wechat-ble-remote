# ESP32 微信小程序 BLE 遥控器

通过微信小程序以 BLE 控制 ESP32；ESP32 再以光耦模拟原遥控器的短按。原遥控器负责原有的射频编码与发射，本项目不会读取、复制或重放射频码。

> 仅用于你有权控制的设备。蓝牙瞬断很常见，因此本项目只提供显式的“锁车/解锁”按钮，**不会**按连接或断开自动触发。

## 特性

- ESP32 MicroPython BLE GATT 外设
- 微信小程序扫描、连接、验证与控制
- 每次连接随机挑战码；未验证连接不能发送控制命令
- GPIO 短按 180 ms，避免长按导致遥控器重复发码
- 光耦隔离：遥控器与 ESP32 不共地

## 接线

每个按键需要独立的 PC817（或 TLP281-4 的一个通道）：GPIO 26（锁车）/GPIO 27（解锁）各经 330 Ω 电阻接光耦 LED 阳极，LED 阴极接 ESP32 GND。光耦三极管两端跨接遥控器对应按键的两块焊盘。

先用万用表确认焊盘；遥控器侧与 ESP32 **不得共地**。不要从遥控器纽扣电池给 ESP32 供电。

## 快速开始

1. 在 `firmware/main.py` 将 `BLE_PAIRING_SECRET` 改为随机长字符串。
2. 在 `miniprogram/app.js` 填入完全相同的字符串；不要提交真实值。
3. 刷入 ESP32 MicroPython 后上传并运行 `firmware/main.py`。
4. 用微信开发者工具导入 `miniprogram/`，执行“构建 npm”，然后以真机预览运行。
5. 授予小程序蓝牙/附近设备权限，点击“连接 ESP32”；状态显示“已验证，可操作”后再使用按钮。

## BLE 协议

ESP32 的自定义服务 UUID 是 `6e400001-b5a3-f393-e0a9-e50e24dcca9e`。连接后状态特征值通知 `CHALLENGE:<nonce>`；小程序回复 `AUTH:SHA256(secret:nonce)`，通过后才能写 `CMD:LOCK` 或 `CMD:UNLOCK`。

## 安全边界

挑战响应避免重放旧连接的认证消息，但 BLE 链路本身不等于车规数字钥匙。不要将本项目暴露为公网控制接口，也不要连接一键启动等高风险功能。需要更高安全性时，应增加硬件安全元件、BLE 配对/加密及距离测量。
